# Feature Roadmap
This roadmap links future enhancements back to Windsurf workflows and the QA flows doc.

## Phase 1 (MVP)
- Report creation, scoring pipeline, AI summary, dashboard, PDF export, manual survey checklist – all described in `docs/qa-user-flows.md`.
- Cost monitoring and environment configuration documented in `docs/external-setup-guide.md`.

## Phase 2 (Post-MVP)
- Multi-location comparison and consultant dashboards
- Reverse recommendation engine ("What business should I open here?") with scoring adjustments
- Financial feasibility (rent pressure, investment modeling)
- Begin capturing ADRs for architecture shifts in `docs/decisions/adr-template.md`

## Phase 3 (Scale)
- Review sentiment and manual survey validation integration
- Franchise suitability reports
- B2B dashboards for enterprise/accelerator teams
- Connect architecture review workflow outputs to production observability docs in `docs/architecture/security-observability-accessibility.md`.
