# ADR Template
Use this template for Architecture Decision Records that deviate from the planned stack or require tradeoffs.

## Title
- Date:
- Status: Proposed / Accepted / Deprecated

## Context
Describe existing architecture (`docs/architecture/system-overview.md`, `docs/technical-specification.md`) and the trigger from QA/user flows.

## Decision
Explain the chosen approach and link to `.windsurf/rules/*` or relevant workflow.

## Consequences
Describe tradeoffs, testing needs (QA verification workflow), and documentation updates (`docs/architecture/*`, `docs/product/*`).
