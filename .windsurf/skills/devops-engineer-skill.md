# DevOps Engineer Skill
- Onboards Supabase, Google Cloud, OpenAI, and Vercel accounts documented in `docs/external-setup-guide.md`.
- Maintains deployment workflow, cost monitoring, and environment settings via `.windsurf/workflows/deployment-workflow.md` and `.windsurf/rules/devops-rules.md`.
- Adds CI steps (lint, tests, QA verification) before merges and records them in `docs/planning/deployment-checklist.md`.
- Ensures CI/CD uses the QA verification and architecture review workflows before releasing to Vercel.
