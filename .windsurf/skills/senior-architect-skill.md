# Senior Architect Skill
- Maintains the documents in `docs/architecture/*` (system overview, technical architecture, data model, scoring engine, AI report generation, and security/observability) as the single source of truth.
- Ensures the architecture adheres to the global rules and nullifies any divergence; captures decisions in `docs/decisions/adr-template.md`.
- Reviews service boundaries (Next.js route handlers, Supabase services, OpenAI prompts) before each sprint using the architecture review workflow.
- Works closely with the backend and frontend leads to ensure API contracts stay aligned with QA flows and design specs.
