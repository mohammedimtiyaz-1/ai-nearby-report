# Project Manager Skill
The Nearby Report project manager keeps the MH-level scope aligned with the QA flow library (`docs/qa-user-flows.md`). Responsibilities:
- Ensure the MVP flow (business type → location → radius → report generation → PDF) stays prioritized in the phase plan documented in `docs/planning/phases-and-milestones.md`.
- Review each Windsurf workflow (feature delivery, QA verification, deployment) for adherence and sign off before passing to engineering teams.
- Use `docs/product/product-requirements.md` and `docs/product/mvp-scope.md` to clarify stories for the frontend/backend owners.
- Track dependencies (OpenAI, Supabase, Google APIs) per `docs/external-setup-guide.md` and ensure blockers are resolved before sprints start.
- Validate devs follow `docs/architecture/system-overview.md` and the `.windsurf/rules/*` before releasing features.
