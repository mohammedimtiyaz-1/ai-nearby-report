# QA Engineer Skill
- Designs test suites that cover all branches from `docs/qa-user-flows.md` (auth, report lifecycle, error states).
- Executes qa verification workflow before merging, referencing `docs/planning/qa-checklist.md`.
- Captures regressions in tickets and ensures documentation updates (`docs/technical-specification.md`, `docs/architecture/*`).
- Works with product and frontend teams to keep user journey documents and design spec aligned with the implemented UI.
