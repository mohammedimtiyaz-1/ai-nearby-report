# Milestone Delivery Workflow
1. Define milestone success criteria from `docs/technical-specification.md` (e.g., report generation pipeline, AI summary reliability, PDF export under 45s) and align them with `docs/qa-user-flows.md`. (Project Manager Skill, Senior Architect Skill)
2. Assign features to sprints in the milestone via the implementation plan and track dependencies through the skill owners (frontend/backend/devops/QA). (Project Manager Skill)
3. Execute features using existing workflows and capture completion status, referencing `docs/planning/sprint-template.md`. (Frontend Skill, Backend Skill)
4. Run milestone QA using the QA checklist and record any findings in `docs/planning/qa-checklist.md`. (QA Skill)
5. Conduct architecture review to confirm scoring and AI components remain align with `docs/architecture/scoring-engine.md` and `docs/architecture/ai-report-generation.md`. (Senior Architect Skill)
6. Present the milestone to stakeholders with updated docs in `docs/product/mvp-scope.md` and note any ADRs for future work. (Project Manager Skill)
