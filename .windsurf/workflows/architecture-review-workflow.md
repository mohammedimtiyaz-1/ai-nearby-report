# Architecture Review Workflow
1. Schedule architecture reviews whenever a new feature touches scoring, AI summaries, or PDF generation as noted in `docs/qa-user-flows.md`. (Senior Architect Skill)
2. Reference the system overview, technical architecture, and data model docs so reviewers understand current boundaries. (Senior Architect Skill)
3. Document reviewer comments and decisions in `docs/decisions/adr-template.md`. (Senior Architect Skill, Project Manager Skill)
4. Update architecture docs with agreed changes and link them to the corresponding workflow entries. (Senior Architect Skill)
5. Ensure DevOps and QA teams sign off via the QA verification workflow before moving to deployment. (DevOps Skill, QA Skill)
6. Archive the review output in `docs/planning/implementation-plan.md` for future retrieval. (Project Manager Skill)
