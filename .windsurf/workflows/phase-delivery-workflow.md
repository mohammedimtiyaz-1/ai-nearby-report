# Phase Delivery Workflow
1. 🔍 Review goals in `docs/planning/phases-and-milestones.md` (Day 1 foundation, Day 2 AI integration, etc.). (Project Manager Skill, Senior Architect Skill)
2. 🧱 Allocate features to the phase via `docs/planning/implementation-plan.md` and confirm dependencies (Supabase, OpenAI, Vercel) are ready per the external setup guide. (Project Manager Skill, DevOps Skill)
3. 🛠 Pair teams to execute features via the feature delivery workflow, ensuring architecture/QA rules are enforced. (Frontend Skill, Backend Skill, QA Skill)
4. 🧑‍🏫 Hold mid-phase architecture and QA reviews (see `architecture-review-workflow.md` and `qa-verification-workflow.md`). (Senior Architect Skill, QA Skill)
5. 🧾 Document outcomes in `docs/planning/phases-and-milestones.md`, updating the QA checklist and product requirement docs as needed. (Project Manager Skill)
6. 🟢 Close phase by verifying reports dashboard, scoring, and AI summary flows from `docs/qa-user-flows.md`. (QA Skill, Senior Architect Skill)
